# Hangman Game

## Introduction

This project implements a classic Hangman game using Python and Tkinter for the graphical interface. Players can select from different word categories (animals, fruits, countries) and attempt to guess the hidden word within a limited number of tries.

## Features

- **Graphical User Interface:** Utilizes Tkinter to create an interactive interface with buttons, labels, and images.
  
- **Word Categories:** Offers multiple categories for gameplay variety.
  
- **Game Mechanics:** Implements core Hangman game logic including guessing letters, managing incorrect attempts, and tracking guessed letters.
  
- **Limited Attempts:** Players have a set number of attempts to guess the word correctly.
  
- **Hint System:** Provides limited hints to reveal a letter from the hidden word.
  
- **Win/Lose Pop-ups:** Displays messages upon winning or losing the game, with options to replay or exit.
  
- **Image Handling:** Integrates images to represent the game's progress visually.

## Modules Used

- **Tkinter:** For creating the game interface and managing GUI elements.
  
- **Random:** For selecting random words from predefined lists.

## Getting Started

1. **Installation:**
   - Ensure Python 3.x is installed on your system.

2. **Running the Game:**
   - Clone the repository.
   - Navigate to the directory and run:
     ```
     python HangmanCode.py
     ```
   - Follow on-screen instructions to play the game.

## Usage

- Upon launching the game, select a category (animals, fruits, or countries).
- Guess letters by clicking on them.
- Use the hint button sparingly to reveal a letter from the word.
- Win the game by guessing the entire word correctly within the allowed attempts.
- Lose if all attempts are exhausted without guessing the word.
